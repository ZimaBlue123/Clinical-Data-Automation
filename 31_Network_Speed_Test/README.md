# 31_Network_Speed_Test

实时网速测试：国内网 / 国外网 / VPN 对比；局域网占用排查（在线设备 IP/MAC + 路由器限速指引）。

## 功能

| 类别 | 说明 |
|------|------|
| **局域网** | 网关 Ping；菜单 4 扫描在线设备 |
| **国内网** | 百度 / 阿里云镜像 / 网易等探针 |
| **国外网** | Cloudflare 测速块、Google 探活等 |
| **VPN** | 系统直连 vs 本地 SOCKS 对比 Mbps |
| **占用排查（菜单 4）** | ARP + Ping 列设备 IP/MAC，指引路由器 QoS 限速 |

> 已移除「对路由器首页 HTTP 压测」：家用路由通常无测速文件，`http://192.168.x.1/` 会得到 0 Mbps，无实际价值。

## 依赖

- `requests`（见根目录 `requirements.txt`）
- VPN SOCKS 对比需 **`PySocks`**

## 快速开始

```bash
cd 31_Network_Speed_Test
python network_speed_test.py
```

- **网速慢、查谁占网** → 选 **4**
- **测外网 / VPN** → 选 **1** 或 **2**

## 交互菜单

| 序号 | 功能 |
|------|------|
| 1 | 完整测速（局域网 + 国内 + 国外 + VPN） |
| 2 | 快速测速（跳过 VPN） |
| 3 | 仅局域网（网关 Ping + 可选单次内网 URL 测速） |
| 4 | **局域网占用排查**【推荐】 |
| 0 | 退出 |

## 菜单 4：能做什么、不能做什么

| 能做 | 不能做 |
|------|--------|
| 列出在线设备 **IP、MAC、Ping** | 显示「某 IP 当前下载多少 Mbps」 |
| 给出路由器 **管理页地址** | 在电脑上直接给别人限速 |
| 说明 **QoS 按 IP/MAC 设下载上限** | ARP 攻击/欺骗 |

实时流量与限速请在路由器：**终端管理 → 流量统计 → QoS/智能限速**。

### 限速参考（不断网）

| 目标 | 路由器下载上限（约） |
|------|---------------------|
| **500 KB/s** | **4 Mbps**（4096 Kbps） |
| **1 MB/s** | **8 Mbps** |

## 常用命令行

```bash
python network_speed_test.py --skip-vpn --save-json
python network_speed_test.py --socks-port 10808
```

## 说明

- 公网测速消耗流量；`--max-mb` 可限制单次下载量。
- 本工具不提供 ARP 类占网/攻击功能；公平限速请用路由器 QoS。
